## 1. Dynamic Asynchronous Directed Acyclic Graph (DAG) Task Planner

The execution kernel schedules distributed compute jobs as mutable DAGs, denoted $\mathcal{G} = (\mathcal{V}, \mathcal{E}, \prec)$, where $\mathcal{V}$ is the set of compute tasks, $\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}$ represents causal state dependencies, and $\prec$ is the strict partial order generated by dynamic vector timestamps.

### Dynamic Topological Sorting via Incremental Kahn Engine
Traditional static schedulers require recomputing $\mathcal{O}(|\mathcal{V}| + |\mathcal{E}|)$ sorts upon graph mutations (e.g., node insertions, dependency deletions, failed sub-graphs). ADMAK uses an incremental dependency tracking algorithm operating over causal frontiers.

```
       [Task A] (Completed: VC=[1,0,0])
          |
          +-------------------+
          |                   |
          v                   v
     [Task B]            [Task C] (Mutates Graph: Spawns C.1)
  (Pending: InDeg=1)   (Running: VC=[1,1,0])
                              |
                              +--------+
                              |        |
                              v        v
                           [Task C.1] [Task D]
```

1. **In-Degree Register ($\mathcal{D}_{in}$):** Each agent maintains a dynamic counter for each node $v \in \mathcal{V}$:
   $$\mathcal{D}_{in}(v) = |\{u \in \mathcal{V} \mid (u, v) \in \mathcal{E} \land \text{State}(u) \neq \text{COMPLETED}\}|$$
2. **Dynamic Cycle Invalidation (Online Tarjan/Depth-First Invariant):** When an edge $(u, v)$ is speculatively added by an agent, the kernel performs a bounded directed cycle check starting from $v$ targeting $u$ using a path-reachability bitset. If a cycle is detected, the transaction aborts with a causal cycle exception.
3. **Speculative Task Dispatch:** When an upstream node $u$ enters state `EXECUTING`, downstream nodes $v \in \text{Adj}(u)$ can speculatively warm their runtime contexts (e.g., pre-fetch model weights, allocate memory buffers) if:
   $$P(\text{Success}(u)) \cdot \text{Cost}(v) > \text{Cost}_{\text{speculative\_waste}}$$

### Causal Dependency Tracking via Vector Clocks
Every task emission and mutation transaction is tagged with a Vector Clock $V: \mathcal{K} \to \mathbb{N}$, where $\mathcal{K}$ is the set of cluster agents. Given two task states with clocks $V_A$ and $V_B$:
* $V_A \le V_B \iff \forall k \in \mathcal{K}, V_A[k] \le V_B[k]$
* $V_A \parallel V_B \iff \neg(V_A \le V_B) \land \neg(V_B \le V_A)$ (Concurrent execution paths requiring state merge).

## 2. Delta-State CRDT Synchronization Engine (10k+ Agents)

State replication across 10,000 agents cannot scale under state-based CRDTs (where the entire state is broadcast) or operation-based CRDTs (which require strictly reliable, ordered causal delivery fabrics). ADMAK employs **Delta-State CRDTs ($\delta$-CRDTs)** with causal context compression.

### Formal Mathematical Specification

A delta-state CRDT is a tuple $(\Sigma, \sqcup, \Delta, \delta)$, where:
* $(\Sigma, \sqcup)$ is a join-semilattice of cluster states.
* $\Delta$ is a sub-semilattice containing mutation differentials.
* $\delta: \Sigma \times \mathcal{M} \to \Delta$ maps current state and a mutation $\mathcal{M}$ to a delta $\delta \Sigma \in \Delta$.
* State integration: $\Sigma_{t+1} = \Sigma_t \sqcup \delta \Sigma$.

#### 1. Delta Positive-Negative Counter ($\delta$-PNCounter)
* **State:** $\Sigma = (P, N)$, where $P, N: \mathcal{K} \to \mathbb{N}$.
* **Increment:** $\delta_{inc}(k) = (P', \mathbf{0})$, where $P'[k] = 1$ and $P'[j] = 0$ for $j \neq k$.
* **Decrement:** $\delta_{dec}(k) = (\mathbf{0}, N')$, where $N'[k] = 1$ and $N'[j] = 0$ for $j \neq k$.
* **Merge:** $(P_1, N_1) \sqcup (P_2, N_2) = (\lambda k. \max(P_1[k], P_2[k]), \lambda k. \max(N_1[k], N_2[k]))$.
* **Value:** $V(\Sigma) = \sum_{k} P[k] - \sum_{k} N[k]$.

#### 2. Last-Write-Wins Element-Set ($\delta$-LWW-Element-Set)
* **State:** $\Sigma = (A, R)$ where $A, R: \mathcal{X} \to (\mathbb{R}^+ \times \mathcal{K})$ map elements $x \in \mathcal{X}$ to a Lamport timestamp and agent tie-breaker.
* **Add:** $\delta_{add}(x, t, k) = (\{x \mapsto (t, k)\}, \emptyset)$.
* **Remove:** $\delta_{rem}(x, t, k) = (\emptyset, \{x \mapsto (t, k)\})$.
* **Merge:** $(A_1, R_1) \sqcup (A_2, R_2) = (A_1 \cup_{max} A_2, R_1 \cup_{max} R_2)$, where:
  $$(M_1 \cup_{max} M_2)(x) = \max_{\text{lexicographical}}(M_1(x), M_2(x))$$
* **Query:** $x \in \Sigma \iff \exists (t_a, k_a) \in A(x) \text{ s.t. } (x \notin \text{dom}(R)) \lor ((t_a, k_a) > R(x))$.

#### 3. Observed-Remove Set with Causal Context Dots ($\delta$-OR-Set)
To eliminate tombstones, elements are coupled with unique causal dots $d = (k, n) \in \mathcal{K} \times \mathbb{N}$.
* **State:** $\Sigma = (E, C)$, where $E \subseteq \mathcal{X} \times (\mathcal{K} \times \mathbb{N})$ is the payload set and $C \subset \mathcal{K} \times \mathbb{N}$ is the causal context (represented compactly as a Version Vector).
* **Add:** $\delta_{add}(x, k)$: Let $n = C[k] + 1$. Return $(\{(x, (k, n))\}, \{(k, n)\})$.
* **Remove:** $\delta_{rem}(x)$: Let $D = \{(x, d) \in E\}$. Return $(\emptyset, D_{\text{dots}})$.
* **Merge:** $(E_1, C_1) \sqcup (E_2, C_2) = (E', C_1 \cup C_2)$ where:
  $$E' = (E_1 \cap E_2) \cup (E_1 \setminus C_2) \cup (E_2 \setminus C_1)$$

### Peer-to-Peer Anti-Entropy Gossip Topology
* **Network Partition:** $N = 10,000$ agents structured as an expander graph (Erdős–Rényi random network $G(n, p)$ with degree $d \approx \log N \approx 14$).
* **Gossip Cycle:** Every $\tau$ milliseconds, each agent selects $\beta$ random dynamic neighbors, sending compressed delta buffers.
* **Bounded Delta Buffers:** Agents preserve outgoing deltas in a bounded ring buffer $\mathcal{B}$. A rolling minimum ACK-vector clock over known peers permits GC on acknowledged intervals, bounding local memory to $\mathcal{O}(|\mathcal{V}_{active}| + |\mathcal{K}_{local\_neighbors}|)$.

## 3. Byzantine-Resilient Consensus & Token-Bucket Rate Limiting

Operating in untrusted multi-agent environments exposes the cluster to state-poisoning and equivocation attacks. ADMAK does not use high-overhead, fixed-epoch PBFT for every mutation. Instead, it embeds a **Byzantine-Tolerant Delta Quorum (BTDQ)** alongside an asymmetric **Token-Bucket CRDT Rate Limiter**.

```
[Agent Incoming Packet]
         |
         v
+-------------------------------+
|  Token-Bucket Rate Limiter    | ---> (Rate Exceeded) -> Drop & Apply Rep Penalty
+-------------------------------+
         |
         v (Within Quota)
+-------------------------------+
| Equivocation & Lineage Check  | ---> (Conflicting Causal History) -> Instant Slash
+-------------------------------+
         |
         v (Valid Lineage)
+-------------------------------+
|  Delta-State CRDT Merge Loop  |
+-------------------------------+
```

### Distributed Token-Bucket Over CRDTs
Each agent $k$ owns a virtual token bucket for write actions, parameterized by capacity $\mathcal{C}_{max}$ and refill rate $\rho \text{ tokens/sec}$. The global token distribution is tracked via a specialized monotonic Delta-PN-Counter:
$$\text{Tokens Available}(k) = \mathcal{C}_{max} - \text{SpentTokens}(k) + \rho \cdot (t - t_0)$$
Any agent whose computed local token count falls below zero is blocked from propagating state mutations.

### Byzantine Behavioral Anomaly Detection
A node $B$ exhibits Byzantine behavior if:
1. **Equivocation:** Generates two divergent deltas $\delta_1, \delta_2$ utilizing the identical dot $(B, n)$ or causal vector clock sequence.
2. **State Poisoning (LWW Timestamp Inversion):** Submits a Lamport timestamp $t_B > t_{local} + \Delta_{drift\_max}$, attempting to permanently pin an LWW key.

```
EQUIVOCATION CONDITION:
Delta 1: (key="job_42", val=ACK, dot=(Node_B, 7))
Delta 2: (key="job_42", val=NACK, dot=(Node_B, 7))
  ===> dot(Delta 1) == dot(Delta 2) ^ Payload(Delta 1) != Payload(Delta 2)
  ===> BYZANTINE PROOF GENERATED -> BROADCAST SLASH
```

### Proof-of-Lineage Verification and Dynamic Reputation Slashing
Every mutation is signed: $\sigma = \text{Sign}_{sk_A}(\text{SHA-256}(x \parallel d \parallel V_A))$.
* If an agent detects equivocation, it assembles a `ByzantineProof`:
  $$\Pi_{Byzantine} = \{ \delta_1, \sigma_1, \delta_2, \sigma_2 \}$$
* Upon receipt of $\Pi_{Byzantine}$, nodes verify both signatures against public key $\text{PK}_A$.
* If verified, node $A$'s balance is set to zero across all cluster sets, its identifier is appended to the local tombstone blacklist, and all mutations causally downstream of $\delta_1, \delta_2$ are invalidated.
